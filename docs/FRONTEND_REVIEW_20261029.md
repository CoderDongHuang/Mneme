### 部署及数据边界

- 个人模型用于用户的交互请求；文档解析、Embedding 与后台任务继续由部署方共享服务提供，以保证索引空间一致。界面已说明，不让个人密钥进入共享索引任务。
- 个人 ZIP 是未加密的个人内容归档，导入为新增副本；账号密码、个人模型密钥、偏好和向量记忆由管理员整站备份覆盖。导入保留历史引用快照，不把旧文档 ID 误链接到新环境；原文件需重建索引后验证检索。
- 宿主机执行器需单独部署、独立令牌和稳定加密密钥。失败时恢复检查点，回滚失败保持服务停止；实际生产 KMS/远端对象存储仍按部署指南操作。
- 自动可访问性检查和截图不能替代所有读屏器的人工认证；模型/OCR 结论需结合原文核对。这里不把数据库替换或界面重构描述为消除所有生产风险。
