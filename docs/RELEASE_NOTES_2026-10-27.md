# 2026-10-27 工程改进与路线图补全

适用个人/小团队私有部署 Beta。接续 PR #30–#33；原要求逐项对照见 [路线图落实记录](ROADMAP_COVERAGE.md)，当前测试见 [最终回归记录](ACCEPTANCE_2026-10-27.md)。

## 本轮行为变化

- 聊天和检索调试支持知识库、文档、标签与导入日期联合筛选；标签编辑、空结果和切库重置可见。服务端将筛选转换成当前用户可检索文档列表，同时限制 Dense 与词法通道，客户端不能覆盖内部允许列表。
- PDF 提供逐页原图与 OCR 区域/置信度叠加，解析内容包含文字层、正文/表格和 chunk 摘要；保存 parser、hash、索引时间、partial 和截断提示。修复多页相同扫描正文被误当页眉页脚清空的问题。
- 引用打开携带原文件 SHA-256；原文、预览与 PDF 页图精确选择版本。历史版本无报告明确说明，未知 hash 拒绝；继续执行租户和删除状态检查。
- 运行中解析可协作取消，等待 Python 退出后清理索引再落库；重试采用新任务 ID，旧取消墓碑保留。替换、删除、重解析和版本恢复拒绝与活动入库竞态。
- 真实模型评测逐项检查 expected_answer_points 的语义覆盖并保存理由；报告比较核对生成/核验 prompt 和模型配置，忽略瞬时熔断计数。
- 备份读取实际 MySQL Flyway 历史，并核对代码迁移名称/CRC32；拒绝空、失败或不匹配的迁移历史。修复 Windows 演练子进程的 UTF-8 解码。
- 资料库加载完成后才可发送问答，带引用/资料等明确证据需求优先进入 QA，避免项目名含“计划”被误作学习建议；手机长用户名自动换行。
- 可选 DashScope 重排验证索引唯一性及 0–1 有限分数，成功但无结果不会恢复被过滤候选；最小分数默认 0，重排默认关闭。评测 provenance 包含改写/重排配置，配置不同禁止直接比较。
- 继续保留之前的声明/引文核验、Embedding profile 保护、离线演示和供应商诊断、删除 saga、恢复前快照与失败回滚。
- 默认关闭网关 SQL 参数调试日志，避免密码哈希、资料正文等绑定值出现在运行日志中；保留 INFO 事件与 trace ID。

## 升级与兼容性

1. 停写，记录 commit/镜像/配置，制作并验证加密备份，另存备份密钥。
2. 网关应用不可改写的 Flyway V19（解析报告）和 **V20（文档标签及版本解析报告）**。实际共 18 条迁移，版本号并非连续计数；旧代码不能直接回滚新 schema。
3. 新筛选字段可省略；内部 `document_ids` 由网关计算。日期按数据库导入时间的自然日边界，不是文档正文中的日期。
4. 新 parser 只在新入库/重解析时生成完整预览，不伪造旧版本报告。旧 Chroma 集合无匹配 profile 时仍需显式 [索引迁移](EMBEDDING_MIGRATION.md)。
5. 按部署指南验证账号、解析、取消重试、版本、问答、删除与恢复；破坏性演练须使用独立数据目录和数据库。

## 验证与仍存边界

Python 623 通过/1 跳过；Java 85 通过/0 跳过（含真实 MySQL V1/V13/V20 迁移）；前端 26 项、lint、生产构建及预算通过。真实桌面和手机覆盖多格式导入、联合过滤、历史版本、权限、测验/复习导出和各功能页面；另测扫描 OCR、多栏表格、损坏文件、活动取消/重试及四类供应商界面诊断。独立空库浏览器、删除故障与备份恢复问答通过，详细证据见最终回归记录。

保留 [此前发布的真实模型基线](https://github.com/CoderDongHuang/Mneme/actions/runs/40477453849)与[复测](https://github.com/CoderDongHuang/Mneme/actions/runs/40479018216)。本轮再次独立运行 2 次 8 题目标模型抽样，均通过并可比；4 题专用集要点覆盖/faithfulness/relevance/拒答为 1.0，但原始首条召回精度 **0.75 < 0.8**，该补充报告整体仍失败，不下调门限或改写历史。离线无答案代理在空标注来源时恒真，不作为真实拒答证据。所有合成小样本不代表用户总体准确率。110 题最终离线门禁通过（P95=15.14ms）；云重排 0.25 阈值在完整集合召回仅 0.5238，因此拒绝默认启用，保留失败报告，详见最终回归记录。

协作取消不能即时强杀外部调用；进程崩溃可能留下最长 12 小时活动锁。复杂 OCR/公式仍需人工核对，报告预览受体积上限约束。真实生产 KMS/异地 S3 和完整许可证人工复核未完成。三项 Chroma、两项 Spring 公告保留有期例外至 **2026-11-10**，见 [安全例外](security-exceptions.md)；隔离/禁用不是补丁，Spring 7 尚未迁移。

## 回滚与恢复

先停写和应用，切回记录的镜像及匹配数据库备份，不逆转 Flyway。恢复失败查看状态报告和 recovery_archive；回滚失败保持停服，修复存储/密钥后用恢复包演练。强杀、断电、磁盘丢失和外部 MySQL 写入不在自动原子回滚保证内。锁遗留须确认原进程退出再处理，不同 checkout 由运维统一协调。恢复包含敏感数据，Windows 设置仅运维可访问的 ACL。
