# 2026-10-27 工程改进批次

适用个人/小团队自部署 Beta，逐项范围见 [路线图落实记录](ROADMAP_COVERAGE.md)。本页不宣称全部产品建议已经实现。

## 行为变化

- 统一检索与回答实际上下文的引用编号；Dense/BM25/RRF 来源可查看通道名次、索引时间和文件版本摘要。
- 资料问答在同步与 SSE 展示前核验声明，要求正确引用及来源中的逐字证据；无法核验时明确拒答。生成提示限制无证据背景补充。首个 QA token 会等待核验完成。
- 云 embedding 失败不再悄悄写入替代向量；profile、维度与异常数值不匹配会明确失败。
- 解析报告标记逐页异常及 partial；保存 parser 版本、内容 hash 和索引时间，前端展示报告。
- 隔离演示不需要模型账号；设置页可检测 Chat/Embedding/Rerank/OCR 服务，并显示可操作的错误分类。
- 恢复前持久保存旧状态；目标导入失败尝试恢复 SQL 和全部数据目录，回滚失败保持应用停止。报告磁盘故障不能阻止回滚；备份文件禁止静默覆盖；同 checkout 备份/恢复互斥。

## 升级与迁移

1. 暂停写入，记录当前 commit/镜像/配置，并验证加密备份能够解密。另存密钥，不把它们放入仓库或公开日志。
2. 网关启动运行 Flyway **V19**（解析报告字段）；已有迁移不可编辑。恢复备份的应用 schema 上限不能高于当前代码。旧归档没有此元数据，须在匹配版本隔离演练。
3. 非空旧 Chroma 集合没有 embedding profile 时会拒绝检索/写入；列表、导出、删除仍可用。停服后先运行 `python-agent/scripts/rebuild_embeddings.py --help`，默认 dry-run，确认集合与模型后显式 apply；保留生成的旧数据快照。
4. 使用 [隔离演示](DEMO.md) 或 [部署指南](SELF_HOSTING.md) 验证上传、partial 报告、查询引用、删除与恢复。演示命名卷不适用正式 bind 目录备份脚本。

## 已知限制与安全例外

模型核验可误判，复杂 OCR/公式/表格、历史版本精确定位仍有边界。日期/标签/文档联合检索过滤、OCR 区域热图与完整解析预览尚未交付。两次同配置模型运行只证明本次小样本可比较，不代表长期稳定性。

三项 Chroma、两项 Spring 公告保留有期例外至 **2026-11-10**，见 [安全例外](security-exceptions.md)。隔离网络与受影响 API 禁用不等于补丁修复，Spring 7 迁移仍需专项完成。

## 回滚与恢复

先停写与停应用，切回记录的代码/镜像和匹配数据库备份；不要依赖旧代码自动回滚 Flyway。恢复失败时检查 `--report` 指定的状态与 `recovery_archive`。回滚失败保持服务停止，修复存储/密钥问题后用恢复包人工演练再启动。强杀、掉电、磁盘丢失和外部 MySQL 写入不在自动原子回滚保证内。

`.backup-restore.lock` 遗留时先核实原进程与状态报告，确认无操作运行后再手动移除；不同 checkout 的操作需运维统一协调。恢复包及临时明文受本机目录权限保护，Windows 应设置仅运维账号可访问的 ACL。
