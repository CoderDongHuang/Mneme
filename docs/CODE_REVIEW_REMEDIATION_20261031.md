## MN-008 / P1-06（上游关闭）：流式资源释放

对照要求：停止、断开、正常结束、错误及超时时显式关闭上游 iterator（如支持 aclose）。本项只覆盖关闭连接；回答/记忆任务解耦及 Gateway 的 stopped/failed 状态区分仍由 MN-007 覆盖，不将整个 P1-06 提前标为完成。

实现：API、主模型、备用模型和个人模型均显式关闭所消费的 iterator。ASGI 响应在发送过程中被取消也在消费任务内关闭生成器；资源释放使用有界、受保护的取消作用域。主动并发监听 HTTP disconnect，包括 ASGI 2.4，避免服务器只在下一次 send 时才感知断开，而模型仍长时间等待下一个 Token。释放错误日志只含异常类型，释放上限为 5 秒。

验证：Python 3.11 Lint 和全套 706 项通过。11 项新增回归覆盖正常/错误/超时、显式停止、取消等待中的模型读取、ASGI send 失败及断开、三种模型路径的底层连接和活跃计数释放，以及真实 Uvicorn/TCP 客户端断开。真实 TCP 测试使用临时本机端口和独立可控模型，第二个 Token 故意永久等待，客户端关闭后 2 秒内关闭 provider 且不调用生成后记忆；不依赖垃圾回收或模型超时。该测试曾复现 ASGI 2.4 的遗漏，加入主动监听后通过。

依据用户提供的《Mneme-全面源码审查与优化清单-2026-10-30.md》逐项处理，每项独立提交、PR 和合并。原始审查文档保留不改；下表仅记录已实际验证的结果。正文中未列入 MN 编号的建议同样纳入后续验收，不以表格项代替全文要求。

验证：Java 全套 100 项通过（含真实 MySQL、V24 旧密文升级 V25、错误密钥、第二行损坏时第一行事务回滚、保留原密文、幂等轮换、连续 v2→v3、JWT 独立轮换、用户/版本 AAD 和管理员拒绝访问）。严格重复 JSON 校验补充后再定向回归。Python 3.11 Lint 与全套 695 项通过，备份恢复文件 49 项通过；缺版本时只读取 Compose 配置，不停服、不修改数据。前端运维页 2 项、Lint、生产构建及包大小检查通过。实际 Compose 空/非空 JSON 密钥环解析通过。真实 http://localhost:3000 启动完成 V25 迁移，隔离 QA 账号通过模型保存、脱敏读回、保留和清除密钥，随后提交删除；证据 artifacts/review-mn003-live.json。

## MN-002 / P1-02：Redis 认证、持久化与可靠队列

对照要求：服务器、Java、Python 使用同一密码；本地允许空密码，生产要求非空；AOF、健康检查和依赖等待；可靠反思任务不得静默转内存。

实现：基础/演示 Redis 显式 AOF everysec，生产强制密码，健康检查携带认证，两个应用等待健康；反思计数、排队故障显式失败，移除本地计数/租约回退。Agent 就绪检查实时 PING 并单列反思队列状态，故障返回 503；普通会话缓存保留降级能力，保存/恢复失败时更新可用状态。生产指南说明完整 AOF/RDB 目录备份与恢复、everysec 的 RPO 边界。

验证：正式 Python 3.11 镜像 Lint 与全套 660 项通过；Spring 真实 Redis Testcontainers 两种密码连接/AOF 配置 2 项通过。`scripts/verify_redis_durability.py` 从实际 Compose 渲染配置验证三方密码/健康依赖；独立 Redis 的空密码和认证模式均通过 Python 实际客户端连接、Stream 写入/消费进入 pending、等待 AOF fsync、SIGKILL、重启、XAUTOCLAIM、执行并 ACK/扣减计数。测试仅使用临时独立容器/网络/卷并清理。故障注入测试确认 Redis 不可用不接受内存任务，排队失败保留计数并释放租约，就绪状态明确降级。

边界：everysec 不是零数据丢失；普通会话缓存与可靠任务的可用性保证不同。生成后的记忆处理解耦按 MN-007 单独修复。

## MN-004 / P1-04：记忆隐私日志

对照要求：记忆写入、去重、确认/拒绝日志只记录元数据，保留错误定位能力，正文不得进入普通日志及 Trace。

实现：移除偏好、去重命中、淘汰、薄弱点强化/衰减、学习进度和拒绝记忆中的原文；补查并移除蒸馏 JSON 解析失败时的模型响应片段。统一记录 operation/result/category/content_length、用户/会话/记忆 ID 的 SHA-256 截断摘要，JSON 日志保留 trace_id。历史记忆 ID 可能包含 user_id，因此也摘要化；授权详情页中的 ID 可用相同算法关联。存储分类读取和反思错误只保留异常类型，不记录可能回显正文的异常消息。Trace 的记忆字段脱敏不能被配置关闭，异常正文仅留摘要和长度。
