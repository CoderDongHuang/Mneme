# Mneme 安全公告处理策略

适用范围包括 Python、Java、前端依赖，容器基础镜像、构建工作流及仓库密钥。

## CI 门禁

- 已修复版本可用的 High 或 Critical 漏洞不得合并；临时例外必须记录 CVE/GHSA、影响判断、负责人和到期日。
- 密钥扫描命中不得合并；确认泄漏后立即撤销凭据并清理历史。
- 每次 PR 和 `main` 推送生成依赖/镜像扫描报告及 CycloneDX SBOM，作为可下载的 CI 产物保留。

## 处理时限

| 严重度 | 首次确认 | 修复或隔离 |
|---|---:|---:|
| Critical | 4 小时 | 24 小时 |
| High | 1 个工作日 | 7 天 |
| Medium | 5 个工作日 | 30 天 |
| Low | 下个计划周期 | 90 天 |

无法在时限内升级时，必须禁用受影响功能、限制暴露面或部署可验证的缓解措施，并在到期前重新审查例外。

## 临时例外

2026-10-01 镜像复扫发现 Jackson Databind `2.21.6` 的 `CVE-2026-91776` 和 `CVE-2026-91777`（High），已将 Jackson BOM 升级到修复版本 `2.21.7`；保持镜像 High/Critical 门禁，不增加例外。

2026-10-01 复核：PyJWT 的 `GHSA-42vr-xj54-vc7v` / `CVE-2026-101918` 已通过升级 `2.14.0` 到 `2.15.0` 修复，锁文件使用核实的官方 wheel 哈希，并覆盖未验签深层 JSON 载荷应返回 `DecodeError` 的回归。启用 LLM 日预算时拒绝非有限预算、价格和共享计数值，且预留的输出 token 上限实际传给模型。备份恢复拒绝目标目录链接及 Windows 特殊文件路径。新扫描仅保留以下三个无修复版本的例外。

本轮复核确认 `PYSEC-2026-3813`、`PYSEC-2026-3814` 和 `PYSEC-2026-3815` 的 OSV 影响范围仍覆盖到 Chroma `1.5.9`，上游尚无修复版本。因此例外仍有效，但依赖和服务镜像已从 `0.5.3` 升级到 `0.6.3`，并补齐 `chroma-hnswlib==0.7.6` 的 Linux 哈希。`pypdf` 已从 `6.16.1` 升级到 `6.19.0`，修复 CI 新发现的 8 个已发布安全公告。Mneme 的 Chroma 端口只绑定 `127.0.0.1`，不向浏览器或公网暴露；Python Agent 是唯一调用方，未启用租户认证或远程模型加载，CI 仅忽略这三个已记录编号，其他漏洞仍失败。上游发布修复后 7 天内升级并删除忽略项，下一次复核不晚于 2026-10-18。
