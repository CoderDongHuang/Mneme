# 共享显示格式约定

## 数字与状态

页面通过 `useFormatters()` 使用用户保存的界面语言；纯函数集中在 `frontend/src/utils/formatters.js`，可用于没有 React 上下文的导出或测试。只格式化显示值，API 参数、数据库标识、版本、CSS 坐标和计算保持原值。

- `number` / `integer` / `decimal`：按 locale 分组，显式精度；缺失、空字符串、布尔值和非有限数显示 `—`，不伪装成零。
- `percent`：输入为比例，`0.125` 显示 `12.5%`。百分制测验分数仍用数字，不再乘一百。
- `bytes`：1024 进位，使用 B / KiB / MiB / GiB；舍入达到 1024 时晋级单位。个人归档限制 50 MiB，与实际 52,428,800 字节校验一致。
- `formatTokens`：非负安全整数或 bigint，保留完整计数；不可恢复精度的浮点整数拒绝展示为精确计数。
- `formatMoney`：调用者必须提供 ISO 货币代码及 `billed`、`estimated` 或 `test_budget` 来源，分别标记供应商账单、估算成本和测试预算。小额费用最多保留六位小数。当前没有真实账单/Token 计费面板，工具提供给后续实际数据展示，不创建模拟账单。
- `status`：集中于 `utils/statuses.js`，区分文档、任务、服务三个语义域。同一个 `processing` 在文档为解析中，在任务为执行中；未知服务端状态保留原值供定位，缺失为未知。

现有分析、图表、记忆置信度、引用检索分数、解析预览、恢复向导、任务、运维、复习、测验和知识库摘要已接入。数量为零保留零，尚无样本则显示暂无样本或 `—`。

## 日期与时区

继续复用 `utils/dates.js` 和 `useDateFormatter()`，不要另建日期格式器。遵循用户的语言和 IANA 时区；纯日历日期及 UTC 聚合统计口径见 [TIMEZONES.md](TIMEZONES.md)。

## 验收

单元回归覆盖缺失值、比例、德语分隔符、IEC 边界、大 Token 数、费用来源和状态语义；运维组件回归验证 API 比例、延迟和容量实际渲染。`e2e/formatters-real.spec.js` 在真实服务创建隔离账号、学习卡与删除任务，保存中英文偏好后读回，验证真实 ZIP 预检大小、复习次数和终态；桌面/移动均运行，结束提交账号删除。该用例加入整栈 CI。
