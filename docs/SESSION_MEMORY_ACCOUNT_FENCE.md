# 会话缓存账号隔离、共享版本与删除围栏

对应原审查 P1-05 / MN-006 的跨存储删除清单、失败传播、独立残留读回与恢复重试。本项覆盖短期记忆、工作记忆和 Redis 会话消息的账号边界；不把单会话删除 Saga、历史留存或物理擦除计为完成。

## 行为

实际运行链路显式传递用户 ID，内存以用户和会话组成键，输入输出消息深拷贝。会话详情和删除接口要求提供用户 ID；这些仍是受内部凭证保护的 Agent 接口，用户归属授权由 Gateway 执行，传入 ID 本身不是鉴权。

短同步事务复用持久 generation 用户锁，读取/写入先检查账号 tombstone；数据库不可读时不能返回本地旧历史。模型调用在事务和内存锁外执行，摘要返回后重新检查版本和历史，迟到结果丢弃，已删账号拒绝发布。线程局部重入只允许同一账号，不能用复制的异步上下文绕过数据库锁；作用域内不得 await 或执行模型调用。

Redis 新消息键使用用户 SHA256 和会话 SHA256 命名空间，载荷带随机版本；版本保存在既有持久用户状态中。不同实例在锁内追加，版本改变时重新读取 Redis；即使 Redis 写失败也推进版本，使其他工作器不能误用旧载荷。随机令牌防止 Redis 写入后数据库回滚时，下次提交重复使用版本而意外恢复孤儿消息。Redis 故障仍可在当前实例保留内存消息，但不宣称这种降级是跨实例可靠持久化。

旧裸会话键仅在新版本尚未建立、严格读取的 manifest 明确记录同一用户时允许恢复。运行时先注册 manifest 再读取会话；损坏或读取失败不能授予归属。升级后的正常写入使用新键，旧键随 TTL 或清理删除，不复制到其他账号。

正式账号删除永久停止写入后，除了 Gateway 的权威会话 ID 批次，还扫描该用户新键前缀清理缺失元数据的孤儿；独立 SCAN/EXISTS 核对，不把静默删除或读取异常当成功。失败保留 manifest 供任务重试。清本实例短期、工作记忆；其他实例每次访问先检查持久 tombstone，拒绝返回旧消息。

## 验证

单元测试覆盖同会话 ID 的跨账号隔离、深拷贝、独立管理器并发追加、Redis 故障和数据库回滚、旧键归属、损坏 manifest、孤儿清理失败重试、模型锁外执行、摘要期间追加/清理/账号删除、数据库不可用及详情接口缺少账号。

`scripts/check_session_memory_fence.py selftest` 在保留 QA 身份上用实际 Redis 和 SQLite/MySQL 分别验证，包含独立 Python 进程读回、并发写与删除、迟到摘要、冷进程拒读、孤儿清理。合成持久状态最后移除。真实页面测试使用独立注册账号及正式账号删除流程，检查任务终态、MySQL/Redis/manifest 零残留、受保护账号的页面会话和迟到写拒绝；不调用外部模型供应商验证摘要竞态。

最终命令、数量和结果写入整改记录，未执行的验证不计为通过。

## 升级与回退

无依赖、配置或数据库结构迁移，但 Redis 载荷及用户状态增加版本字段。停止全部旧应用写入者，保存匹配 SQL、Agent 数据、旧镜像及容器配置后整体升级，不能混用旧写入者。回退时使用匹配数据和镜像；旧版本无法理解新键，不能承诺只回退镜像仍保留升级后对话。SQLite 为单主机，共享实例使用 MySQL 并共享会话目录。

工作记忆仍为实例内窗口，不提供跨进程消息复制。用户状态版本记录的留存和历史备份/WAL/进程堆内存物理擦除属于后续存储生命周期治理。Java 单会话删除尚需跨服务可靠清理，本项账号围栏不能代替该流程；不宣称整份审查或 MN-006 全部完成。
