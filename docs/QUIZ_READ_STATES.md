# 测验读取状态与草稿切换保护

对应审查 P3-03 的测验页读取异常和 P2-14 的渐进拆分；本项不代表全部页面或整个审查已完成。

- 测验列表和资料库独立加载与重试，未读取指标显示 `—`，只有成功空结果才显示空提示。资料库重试不清除创建主题。
- `features/quiz/QuizAttempts.jsx` 单独管理历史加载、重试和过期缓存，旧测验的迟到响应不能覆盖新测验。历史故障不会阻塞草稿读取或作答。
- 草稿读取失败有独立重试，不再永久显示“正在恢复”。保存失败保留当前答案并阻止切换测验或打开历史，重试真实保存成功后才能离开；保存中锁定编辑和其他选择。
- 提交沿用现有 request_id 幂等契约，同一答案失败重试复用编号；成功结果与历史刷新失败分别显示，重试历史不会重发提交。刷新后可重新打开真实历史。
- 生成失败保留资料库和主题，生成成功使用明确回执。新增提示同步提供英文翻译。

真实桌面/手机回归使用正式导入 API 建立确定性题目，仅注入 GET 503。注册、草稿 PUT、提交 POST、历史读取、刷新与账号删除都访问实际 Gateway/数据库；读回草稿内容、唯一作答记录及刷新后结果，未重试整个用例。六张实际视口截图复核，无横向溢出。独立 SQL 核验 QA 用户为零、185 个删除任务均 completed，Gateway/Agent 健康均 200。用例加入整栈 CI。

## 部署与边界

仅修改前端、测试与 CI，无 API/数据库迁移。部署保留旧容器、精确配置和匹配 SQL 快照；回退恢复旧前端即可，不回退业务数据。500ms 自动保存与卸载时尽力保存继续保留；关闭浏览器、断电或跳转其他路由时不保证未确认草稿已持久化。本次保护明确针对同页切换测验和打开历史，不声称离线持久化或所有网络写入恰好一次。
