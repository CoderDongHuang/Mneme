# 设置页读取与保存状态

对应审查 P3-03、P2-14。本项将个人模型配置请求与草稿生命周期迁入 `frontend/src/features/settings/useModelSettings.js`，保留原 API、布局和共享组件。

模型配置与运行状态分别加载、报错和重试。首次读取失败不显示空表单，重试模型配置不重读健康状态；健康刷新不重置模型草稿、错误或保存回执。健康刷新期间不继续展示旧的“服务已连接”，失败明确显示不可用。连接成功仍不代表整个学习流程已通过端到端验证。

保存和测试期间锁定服务商、模型名称、密钥及两个开关，同步锁阻止重复提交。失败保留草稿与密钥输入；保存成功使用服务端回执并清空本地密钥输入。修改草稿清除旧测试成功提示。读取与模型请求在卸载时取消，并拒绝迟到结果；取消 HTTP 不保证后端写入未提交，重新进入页面应读取实际结果。不会自动重试保存或付费模型测试。密钥不写入浏览器存储、日志或测试截图。
