## 仍需维护

1. 三项 Chroma、两项 Spring 公告仍有截至 2026-11-10 的例外，见 [安全响应策略](SECURITY_RESPONSE_POLICY.md)；隔离和受影响 API 禁用不等于补丁修复，Spring 7 迁移尚未完成。
2. 生产 AWS KMS/S3 异地恢复、费用和容量需部署方资源。本轮真实 S3 兼容 RustFS 不代替生产云验收；SBOM 不代替完整许可证人工兼容性审查。
3. 复杂 OCR/公式/表格和模型核验仍可能出错。4 题专用集原始首条检索精度 0.75 < 0.8，失败报告保留；生成层正确拒答不等于检索无无关候选。
4. 取消是协作机制，须等待外部请求返回或超时；Python 强杀可能留下 12 小时活动锁。回滚依赖磁盘、MySQL 与备份密钥可用；掉电/强杀后按状态报告人工恢复。
5. 公网部署还需 HTTPS、SMTP、容量、备份保留和监控；旧版本未保存的解析报告不能当作历史事实补造。
