# Mneme 项目收尾状态

审查日期：2026-10-27。定位为个人和小团队自部署的 Beta 学习助手。当前功能与操作以代码、此页、[路线图覆盖记录](ROADMAP_COVERAGE.md)、[发布说明](RELEASE_NOTES_2026-10-27.md)、[自部署指南](SELF_HOSTING.md)及 [测试说明](testing.md) 为准；旧审计和开发笔记仅作历史记录。

## 已完成的产品闭环

- 账号注册、登录、密码重置、会话撤销；资料库上传、解析、版本恢复和删除；可追溯引用的流式对话。
- 三级记忆、人工确认、学习计划、复习、测验、指标、工作区迁移和隐私操作。
- 中英文 OCR、可选多模态解析、Dense + FTS5 BM25 混合检索、RRF、可选专业重排。
- Compose 本地自部署；自动迁移、基础监控、跨存储删除、加密备份恢复、双节点与真实浏览器 CI 验收。
- 新增无模型账号的隔离演示、设置页供应商检测、逐页解析报告和部分成功状态、Embedding profile/维度保护与显式重建工具。
- 引用编号与实际上下文统一，词法结果重新校验租户实时向量；资料回答在同步/SSE 展示前执行声明与逐字证据检查。
- 备份恢复先建立可校验的操作前快照，失败尝试回滚；回滚失败保持服务停止并保留恢复包和状态报告。

## 尚需持续维护的边界

1. **上游安全公告。** 三项 Chroma 公告及两项 Spring 公告保留有期例外，到期日为 2026-11-10；隔离与受影响 API 禁用不等于补丁修复。详情见 [安全响应策略](SECURITY_RESPONSE_POLICY.md)，Spring 7 迁移尚未完成。
2. **生产现场证据。** 真正的 AWS KMS/S3 异地恢复、生产使用与账单校准需要部署方的资源、密钥和真实样本。代码与受控演练不能代替生产验收。
3. **模型与内容质量。** 低清扫描、复杂公式和表格仍可能出错；模型核验有相关性误判，并非形式证明。新生成/核验流程的模型趋势需要重新采集可比历史；离线检索分数不代表回答准确率。外部调用受供应商、网络和额度限制。
4. **运行范围。** 推荐个人或小团队私有部署。公网服务需自行完成 HTTPS、SMTP、资源容量、备份保留和持续监控；现有容量证据只覆盖 CI 测试拓扑。

5. **一致性与覆盖范围。** 恢复回滚依赖本机磁盘、MySQL 和备份密钥仍可用；掉电/强杀后须按状态报告人工恢复。入库跨 Chroma/FTS 不是整体事务。日期/标签联合检索过滤、逐区域 OCR 置信度热图尚未实现，见覆盖记录。

以上是明确边界，不应宣称全部完成或生产级。用户设计笔记 `调试问题记录.md` 保留原样。
