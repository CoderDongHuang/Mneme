# Mneme 项目收尾状态

审查日期：2026-10-08。适用版本：本次收尾发布，定位为个人和小团队自部署的 Beta 学习助手。当前功能与操作以代码、此页、[自部署指南](SELF_HOSTING.md)、[测试说明](testing.md)及发布页为准；旧审计和开发笔记仅作历史记录。

## 已完成的产品闭环

- 账号注册、登录、密码重置、会话撤销；资料库上传、解析、版本恢复和删除；可追溯引用的流式对话。
- 三级记忆、人工确认、学习计划、复习、测验、指标、工作区迁移和隐私操作。
- 中英文 OCR、可选多模态解析、Dense + FTS5 BM25 混合检索、RRF、可选专业重排。
- Compose 本地自部署；自动迁移、基础监控、跨存储删除、加密备份恢复、双节点与真实浏览器 CI 验收。
- 本次修复了登录页画面对比度、空闲反思队列误报超时，以及备份遗漏 Redis 反思任务的问题。

## 尚需持续维护的边界

1. **上游安全公告。** Chroma 的三项公告目前仍处于有期隔离例外，详情和 2026-10-18 复核期限见 [安全响应策略](SECURITY_RESPONSE_POLICY.md)。隔离降低暴露面，不等于修复漏洞；到期前须复核上游并更新处置。
2. **生产现场证据。** 真正的 AWS KMS/S3 异地恢复、生产使用与账单校准需要部署方的资源、密钥和真实样本。代码与受控演练不能代替生产验收。
3. **模型与内容质量。** 低清扫描、复杂公式和表格仍可能出错；外部模型调用取决于供应商、网络和额度。重要内容应核对原文，评测分数不能保证任意输入准确。
4. **运行范围。** 推荐个人或小团队私有部署。公网服务需自行完成 HTTPS、SMTP、资源容量、备份保留和持续监控；现有容量证据只覆盖 CI 测试拓扑。

这些是已知限制和持续运营事项，不应写成已解决或宣称生产级。历史设计建议见 `调试问题记录.md`；未采纳的可选设想不阻碍当前 Beta 收尾。
