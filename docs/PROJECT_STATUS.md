## 仍需维护

1. 向量存储已切换 Qdrant 1.20.0，并删除 Chroma 三项例外；Spring 使用 Boot 4.0.9 / Framework 7.0.10。旧数据必须按[迁移指南](VECTOR_STORE_MIGRATION.md)显式迁移，旧镜像只可隔离恢复。
2. 生产 AWS KMS/S3 异地恢复、费用和容量需部署方资源。本轮真实 S3 兼容 RustFS 不代替生产云验收；SBOM 不代替完整许可证人工兼容性审查。
3. 复杂 OCR/公式/表格和模型核验仍可能出错。四组 140 题离线门禁通过，新增中文具体名词过滤是有限启发式，存在误拒答和跨语种盲区。8 题真实模型通过不代表总体准确率；云检索 704.57ms 仅通过新设 3000ms 云预算，旧 250ms 失败报告保留。
4. 取消是协作机制，须等待外部请求返回或超时；活动锁现使用 60 秒 owner 租约并每 20 秒续租，进程强杀后最迟一个租约周期可重试。租约丢失会在下一个解析检查点停止处理；这不是 fencing，检查与写入之间的暂停竞态仍存在；回滚仍依赖磁盘、MySQL 与备份密钥可用。
5. 公网部署还需 HTTPS、SMTP、容量、备份保留和监控；旧版本未保存的解析报告不能当作历史事实补造。
