# 个人恢复：校验归属、未知结果与下载生命周期

对应原审查 P3-03、P2-14，并沿用 P3-02/P3-04 的共享日期、大小、反馈和状态组件。本项只拆个人恢复请求边界，不修改归档格式、服务端恢复算法或现有 API。无新增依赖、配置、CSS 或数据库迁移。

## 行为

请求迁入独立 hook，删除页面原请求实现。重新校验先撤销旧成功；失败不能保留“通过”。改变文件或范围取消旧校验，响应还必须属于当前选择和请求，即使传输忽略取消也不能覆盖新预览。校验响应检查范围、大小、摘要、兼容性、恢复模式、覆盖数量和可渲染字段，非法响应明确失败。恢复提交重新检查当前预览、步骤及确认语句，同步锁阻止重复 POST。

成功导入显示关系数据提交和文件恢复数量，索引仍需等待任务完成后验证，不冒充全部检索已就绪。提交失败或非法回执视为结果未确认，撤销旧校验并阻止当前挂载中的重复提交；用户须到资料库、会话或学习页核实后，明确点击“已核实结果，重新选择归档”。重置同时清除真实文件输入。

该限制是当前挂载中的客户端保护，不是服务端持久幂等。离页、刷新或客户端取消不能撤销服务端已接受的导入；重新进入前仍须核实真实数据，重复导入可能产生副本。后续跨请求持久去重必须独立设计，不可把本项描述为恰好一次恢复。

离页取消校验、提交和下载等待，拒绝迟到更新；下载在读取响应体后再次检查取消，即使响应体忽略取消也不能再创建下载链接。账号 ID 改变重新挂载整个恢复视图，个人预览、下载记录和管理员数据不会留给下一账号。切换页面标签仍保留当前个人向导，不把标签切换误认为服务端操作撤销。

## 验证与范围

单元覆盖重校验失败、选择竞态、非法字段、重复提交、卸载、账号变化、下载取消和未知结果显式重置。全量前端、Lint、生产构建及原包大小门禁通过。真实 localhost 桌面和手机使用隔离账号，实际下载 ZIP、预览、恢复文件与学习卡，并独立 GET 验证数量与原文件内容，等待文件 ready。第二次导入在实际服务端提交后仅截断浏览器回执，确认界面报告未知且不重复 POST；只读校验故障和延迟响应用于验证归属。下载取消等待实际 React 页面卸载后再释放延迟响应，不只以 URL 变化判断离页。

原演练和整站恢复真实回归再次执行；权限、未配置状态和明确夹具边界仍按各自文档，不触发整站覆盖。测试关闭自动 Trace/录像，仅保存明确安全截图；账号通过正式删除接口清理，独立 SQL、部署文件哈希及健康读回记入整改记录。真实个人恢复回归加入整栈 CI。

部署前停止全部应用写入者，保留停写 SQL、旧容器和配置后切换前端。本项可切回保留前端镜像；与其他批次联合回退须恢复对应镜像和匹配数据点，不能只恢复旧 SQL。
